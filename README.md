# AI Demand Forecasting Model (Spreadsheet)

This repository contains a **Google Sheets / Excel-ready demand forecasting model** with a clean worksheet structure and guided UI/UX setup.

## Deliverables

- `templates/Historical_Data.csv` — input template for historical monthly demand.
- `templates/Model_Inputs.csv` — model controls (horizon, confidence, lead time, seasonal multipliers, promo uplift).
- `templates/Forecast_Output.csv` — forecasting sheet template with formulas (to paste into Google Sheets/Excel).
- `templates/Dashboard_KPIs.csv` — KPI summary table for dashboard cards.
- `docs/SETUP_AND_UX_GUIDE.md` — step-by-step implementation and UI/UX instructions.

## Outcomes Supported

- Better sales and inventory planning.
- Fewer stockouts and overstock situations.
- Reduced waste through improved demand signal visibility.

## Time to Implement

Typical rollout: **1–3 months** (data cleaning, model tuning, and operational adoption).

## Required Inputs

- Historical sales data.
- Seasonal information.
- Promotions calendar.

## AI Tooling Paths

- Amazon Forecast
- Azure AutoML Time Series (AutoML Forecasting)
- Open-source (Facebook Prophet)
